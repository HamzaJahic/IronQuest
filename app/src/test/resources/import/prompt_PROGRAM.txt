Format (keep the header row and the column names exactly as shown):

day,exercise,sets,rep_min,rep_max,type,stat,increment_kg,superset

Rules:
- One row per exercise. Rows of the same day go together, in training order; the first exercise of a day is its main lift.
- day: name of the workout day (max 60 characters).
- sets: 1-20. rep_min and rep_max: the target rep range (for type "minutes" it is minutes).
- type: "reps" for weight x reps, "minutes" for cardio.
- stat: STR (upper body), CON (legs), STA (cardio).
- increment_kg: weight added when every set reaches rep_max (2.5 usually, 5 for big lower-body lifts, 0 for cardio).
- Each exercise at most once per day.
- superset: optional, usually empty. To do exercises as a superset (alternating one set of each), give them the same label (A, B, …). A superset's rows must be next to each other in the same day, and it needs at least 2 exercises.
